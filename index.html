IT Operations Toolkit

The rule for these scripts: show the plan, then let me decide. Log Manager compresses older logs, File Organizer sorts by file type, and Disk Monitor checks a threshold I choose.

What each one does +

Log Manager compresses logs older than seven days and clears old archives. File Organizer sorts by extension. Disk Monitor checks a configurable usage threshold.
